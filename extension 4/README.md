# Scoutly Price Scout

Chrome extension MVP for detecting a product on the current page and helping shoppers compare it across trusted shopping search engines.

## Load locally

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Choose **Load unpacked** and select this directory.
4. Open a product page, then click the Scoutly icon.

This MVP does not claim a live lowest price. It detects product context, opens comparison searches, and stores local price watches. A verified retailer/API backend is required before showing automated price claims or sending alerts.

1. Choose the use case

Calls and work

Prioritise: microphone test evidence, voice pickup, comfort and multipoint support.

Reject if: the listing only claims “clear calls” without identifying the model or microphone setup.

Commuting

Prioritise: stable fit, passive isolation, battery evidence and a usable return window.

Reject if: the listing hides the exact generation or sells a different variant under a similar name.

Study and everyday listening

Prioritise: comfort, controls, battery, codec support and warranty clarity.

Reject if: the “discount” is based only on an inflated MRP rather than the final payable total.

What a trustworthy shopping agent should return

  • Exact brand, model code and variant match
  • Current price, currency, seller and delivery estimate
  • Final payable total, including delivery and conditions
  • Return policy, warranty and stock status
  • Source link, timestamp and confidence level

When any of these fields are unavailable, the agent should label the result “needs verification” instead of presenting a confident winner.

Short FAQ

What is the best wireless headphone under ₹3,000?

There is no universal winner. Pick the use case, then choose the listing with the strongest verified evidence and lowest final delivered total.

Why does exact model identity matter?

Headphone names often span multiple generations, colours and bundles. The model code is the stable key for comparing like with like.
